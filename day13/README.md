# Bole Buna Cafe Business Profile

This project was created for CodeOps Module 2, Day 13.

## Business

Bole Buna Cafe is a fictional Ethiopian coffee shop located in Bole,
Addis Ababa.

## Files

- index.html — business profile card
- styles.css — profile card styling
- exercises.html — Day 13 CSS exercises
- README.md — project documentation

## CSS Techniques Used

- CSS custom properties with :root
- var() for colors, spacing, radius, and fonts
- Global box-sizing: border-box
- Google Fonts
- Box model properties
- HSL colors
- Hover states
- Visible keyboard focus
- ::before pseudo-element
- Typography hierarchy
- Border radius
- Box shadow
- Centered card layout
- Table zebra striping with nth-child

## How to Run

Open index.html in a web browser.

Open exercises.html to view the five Day 13 exercises.
