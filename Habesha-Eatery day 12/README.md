# Habesha Eatery

## Project Description
Habesha Eatery is a two-page website created for the CodeOps Module 2 Day 12 mini-project.

## Features
- Home page
- Contact page
- Accessible contact form
- Opening hours table
- Responsive design
- Semantic HTML5
- CSS styling

## Files
- index.html
- contact.html
- styles.css
- README.md

## How to Run
1. Download the project files.
2. Open index.html in a web browser.
3. Use the navigation menu to visit the Contact page.
